# Gojūon Study - Japanese Character Learning Extension

A Chrome extension designed for learning Japanese characters through active recall. Perfect for practicing hiragana and katakana during work breaks or study sessions.

## Features

- **Complete Character Sets**:
  - Basic gojūon (五十音) characters
  - Dakuten (濁点) voiced sounds
  - Handakuten (半濁点) half-voiced sounds
  - Both hiragana (平仮名) and katakana (片仮名)

- **Customizable Learning**:
  - Choose between hiragana only, katakana only, or both
  - Preferences are saved between sessions
  - No repeated characters in consecutive displays

- **User-Friendly Interface**:
  - Clean, minimalist design
  - Click once to reveal pronunciation
  - Click again for a new character
  - Shows writing system type (平仮名/片仮名)

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/[your-username]/gojuon-study.git
   ```
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the cloned directory

## Usage

1. Click the extension icon in your Chrome toolbar
2. Select your preferred character set (hiragana, katakana, or both)
3. Click the displayed character to see its pronunciation in romaji
4. Click again to get a new random character
5. Practice regularly during work breaks!

## Character Coverage

- **Basic Gojūon**: あ行, か行, さ行, た行, な行, は行, ま行, や行, ら行, わ行
- **Dakuten**: が行, ざ行, だ行, ば行
- **Handakuten**: ぱ行
- All corresponding katakana characters
